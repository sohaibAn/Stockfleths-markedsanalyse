# Markedsføringsanalyse: Stockfleths (AOS120)

Dette prosjektet ble gjennomført som en del av kurset AOS120 – Markedsføring ved Handelshøyskolen NMBU.

## 📄 Om prosjektet
Vi analyserte hvordan kaffebaren Stockfleths på Ski Storsenter skiller seg ut fra konkurrentene, med fokus på markedsføringsmiksen: produkt, pris, plass og påvirkning.

## 🔍 Innhold
- Sammenligning med andre kaffebarer som Espresso House og Joe & the Juice
- Bruk av observasjoner, kundeintervjuer og prisdata
- Drøfting av hvordan Stockfleths bruker tradisjonell merkevarebygging og strategisk plassering
